# My vss site

Run commands from this directory:

```sh
vss build
vss serve
```

Edit `index.md`, customize `layouts/`, and put assets in `static/`.
The development server rebuilds on changes; reload your browser to see updates.
Publish the contents of `dist/` after setting `base_url` in `vss.toml`.
Do not put private files in the site directory: Markdown is discovered recursively.

Documentation: https://vss.veltiosoft.dev/
