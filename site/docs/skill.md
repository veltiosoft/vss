# AI Agent 向けの SKILL をインストールする

`vss skill install --dir <DIR>` は、vss の基本操作と設定方法を説明する `SKILL.md` を配置します。
SKILL はバイナリに同梱しており、ネットワーク接続は不要です。
サイト外でも実行でき、`vss.toml` は読み込みません。

## 配置先を指定する

`--dir` は SKILL の親ディレクトリを指定する必須オプションです。
Agent が参照する保存先を利用者が選び、明示的に指定してください。
vss は Agent の種類や既定の保存先を判定しません。

```sh
vss skill install --dir ./path/to/skills
```

配置構造は次のとおりです。

```text
path/to/skills/
└── vss/
    └── SKILL.md
```

相対パスはコマンド実行時のカレントディレクトリが基準です。
絶対パスも指定できます。
空白を含むパスは引用符で囲んでください。

```sh
vss skill install --dir "/absolute/path/agent skills"
```

親ディレクトリが未作成なら、中間ディレクトリも含めて作成します。
既存の親ディレクトリに別の SKILL やファイルがあっても、それらは変更しません。
Agent 固有の設定ファイルも書き換えません。
サイト内に配置する場合は、SKILL 自体がページ化されないよう、隠しディレクトリを使うか `build.ignore_files` で除外してください。

## 成功とエラー

成功時は、配置した `SKILL.md` の絶対パスを表示します。
次の場合は原因を示すメッセージを出力し、非ゼロの終了コードを返します。

- `--dir` が未指定、値が未指定、または空文字列の場合。
  ファイルやディレクトリは作成しません。
- 親ディレクトリやその途中のパスが通常ファイルの場合。
- 親ディレクトリに書き込み権限がない場合。
- 親ディレクトリ内に `vss` という名前のエントリーが既にある場合。
  通常ファイル、空のディレクトリ、壊れたものを含むシンボリックリンクも拒否します。
  既存の内容は上書きしません。

上書きオプション、自動更新、アンインストールは提供していません。
既存の SKILL を残す場合は別の親ディレクトリを指定してください。
I/O エラーで失敗した場合は、新しく作成したディレクトリや書きかけのファイルが残ることがあります。

ヘルプは次のコマンドで確認できます。

```sh
vss skill --help
vss skill install --help
```
