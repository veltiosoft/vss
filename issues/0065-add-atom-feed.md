# 公開記事から Atom フィードを生成する方法を検討する

- Created: 2026-10-28
- 状態: 未着手
- 優先度: P2
- ラベル: `enhancement`, `migration`
- 元 issue: なし（ローカル起票）

## 背景と課題

移行元サイトは `/feed.xml` に公開記事の Atom フィードを出力している。
同梱スキルにはフィード生成の説明がなく、移行時には別途生成処理が必要と見込まれる。
実装前に既存機能を確認する。

## 検討事項

- Atom の生成を vss 本体で行うか、一覧データの公開などで外部生成を支援するか。
- 絶対 URL、更新日時、日付のタイムゾーン、XML のエスケープと空フィード。
- 下書きの除外（[0063](closed/0063-add-draft-exclusion.md)）と URL 方針（[0062](0062-add-pretty-urls.md)）の共有。
- 静的ファイルとの衝突と serve 時の更新。

## 完了条件

- [ ] 対応方針と必要な設定、日付の扱いを文書化する。
- [ ] 選択した方式で XML の妥当性、URL、公開対象、更新を検証する。
