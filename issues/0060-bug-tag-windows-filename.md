# bug: タグページの出力ファイル名を OS 非依存にサニタイズする

- Polished: {YYYY-MM-DD}

## 目的

タグ名は URL ではパーセントエンコードされるが、出力ファイル名には生のタグ名が使われる。Windows で無効な `?`、`*`、`<`、`>`、`|`、`"` や末尾のドット・空白を含むタグでビルドが失敗するため、出力ファイル名をサニタイズする。

## 現状

確認対象: `main` の `db75abf`（v0.21.0）。

- `src/subcommand_build.rs` の `is_safe_tag_name` は `..`、`/`、`\`、`:`、制御文字を拒否する。
- `tag_url` は URL セグメントをパーセントエンコードする。
- `tag_output_path` は `config.build.tags.url_pattern.replace("{tag}", tag)` をそのまま `Path::new(&config.dist).join(...)` に使い、生のタグ名をファイル名にする。
- Windows のファイル名で無効な `?`、`*`、`<`、`>`、`|`、`"`、末尾のドット・空白は拒否されない。`fs::create_dir_all` / `fs::write` が失敗し、ビルド全体が止まる。
- macOS / Linux では同名のファイルを作成できるため、クロスプラットフォームで挙動が異なる。

## 設計方針

- URL 用のタグ名（パーセントエンコード）とファイル名用のタグ名を分離する。
- ファイル名用には Windows の予約名（`CON`, `PRN`, `AUX`, `NUL`, `COM1` など）と無効文字、末尾のドット・空白を安全な表現へ置換する。
- 置換後の名前が衝突しないよう、必要ならハッシュや連番を付ける。ただし既存の URL との対応を壊さない。
- 不正なタグ名を拒否するか、安全なファイル名へ変換するかを決め、テストで確認する。

## 完了条件

- [ ] Windows で無効な文字を含むタグ（`a?b`、`a*b`、`a<b`、`a|b`、`a"b`、末尾ドット・空白）でビルドが失敗しない。
- [ ] 生成されたタグページが、対応するタグ URL から到達できる。
- [ ] 既存の安全なタグ（英数字、日本語、`C++`、`a b`）の URL と出力先が変わらない。
- [ ] macOS / Linux / Windows で同じタグ集合のビルド結果が一致する。ファイル名の差し替え規則を文書化する。
- [ ] 回帰テストを追加し、`cargo test --all --locked` が成功する。

## 対応状況

- `a?b` を現行の `is_safe_tag_name` が受け付けることを、追加した回帰テストの失敗で確認した。Windows 固有のファイル作成失敗はローカルの macOS では直接再現していない。
- 設計方針の「不正なタグ名を拒否」を採用した。Windows の無効文字・末尾ドット/空白・予約デバイス名を含むタグは、すべての OS でリンクとタグページの生成対象から除外する。ビルドエラーにはしない。
- 名前の置換をしないため置換による衝突は発生しない。英数字・日本語・`C++`・`a b` の URL と出力先は変更していない。規則を README に記載した。
- 全体ビルド・増分ビルドで不正なタグが出力されないことと、既存タグの URL から対応する出力先を HTTP 配信できることをテストした。macOS / Windows CI にビルド単体テストも追加した。
- 最終検証で `cargo test --all --locked` の全 78 テスト、Clippy、フォーマット・差分検査が成功した。OSV で全 326 依存を再検査し、既存の `proc-macro-error` の未メンテナンス警告以外の検出はなかった。
- macOS でローカル検証済み。Linux / Windows の CI 実行結果は未確認であり、3 OS の実測一致までは確認していない。
- Windows CI で、テンプレートキャッシュの `\\` 区切りと設定の `/` 区切りが一致せずタグテンプレートを検出できない既存不具合も確認した。キー生成・検索・増分更新の区切りを統一し、入れ子のテンプレートを検索する回帰テストを追加した。
- Windows CI で、拡張長プレフィックス付きのサイト内変更パスがサイト外と誤判定されることも確認した。プレフィックス形式だけの差を照合時に吸収し、既存ファイル・削除済みファイルの受理と、サイト外パスの拒否をテストした。
