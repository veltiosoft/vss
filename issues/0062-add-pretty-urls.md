# 既存サイトのパーマリンクを維持できる出力方式を検討する

- Created: 2026-10-28
- 状態: 未着手
- 優先度: P2
- ラベル: `enhancement`, `migration`
- 元 issue: なし（ローカル起票）

## 背景と課題

Astro サイトからの移行調査では、記事 URL の `/posts/hello/` を維持したい。
vss は Markdown のパスから出力パスを決め、`posts/hello.md` を `posts/hello.html` に変換する。
`post_slug` は出力パスを変更しない。
入力ファイルの再配置や後処理で回避できるが、生成されるタグリンクや内部リンクも整合させる必要がある。

## 検討事項

- ディレクトリ形式の URL、既存パーマリンクの指定方法と既定動作との互換性。
- 出力先の重複、パストラバーサル、静的ファイルやタグページとの衝突の検出。
- 日本語や特殊文字を含むパス、正規 URL、タグページのリンク、serve 時の更新。
- ホスティング側の URL 解決仕様に依存する部分の明記。

## 完了条件

- [ ] 対応方法と非対応の範囲を決定し、既存の `.html` 出力との互換性を文書化する。
- [ ] 選択した仕様で URL、リンク、衝突、増分ビルドをテストする。
