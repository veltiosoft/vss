## 目的

AI Agent が vss の使い方を参照できる SKILL を、vss の CLI からインストールできるようにする。
Agent ごとのインストール先を vss 側で管理すると、対応先の追加や仕様変更への追従が必要になる。
そのため、利用者がインストール先のディレクトリを明示する方式を第一案とする。

## 実装前の現状

`src/main.rs` のサブコマンドは `build`、`serve`、`new`、`self` で、SKILL をインストールするコマンドはない。

## 確定した CLI と配置仕様

```sh
vss skill install --dir ./path/to/skills
```

`--dir` に SKILL の親ディレクトリを指定し、その配下の `vss/SKILL.md` に配置する。
初期実装の同梱ファイルは `SKILL.md` のみとする。

- インストール先の指定は必須とし、Agent 固有の既定パスへ暗黙に書き込まない。
- 相対パスはコマンド実行時のカレントディレクトリを基準とし、絶対パスや空白を含むパスも受け付ける。
- 未作成の親ディレクトリは中間ディレクトリも含めて作成する。
- `skills/vss/SKILL.md` をバイナリに同梱し、ネットワーク接続なしで配置する。
- 既存の `vss` は、空のディレクトリ、通常ファイル、壊れたものを含むシンボリックリンクも拒否する。無関係なファイルは変更しない。
- 成功時は配置した `SKILL.md` の絶対パスを表示し、失敗時は原因が分かるメッセージと非ゼロの終了コードを返す。
- I/O エラー時は、新しく作成したディレクトリや書きかけのファイルが残る場合がある。

## 対象外

- Agent の種類の検出、Agent ごとの保存先一覧の管理、自動インストール先選択。
- Agent 固有の設定ファイルの書き換え。
- 任意の外部 SKILL の検索やダウンロード。
- SKILL の自動更新やアンインストール（必要になれば別 issue とする）。
