# 既存サイトからの移行と出力検証の手順を整備する

- Created: 2026-10-28
- 状態: 未着手
- 優先度: P3
- ラベル: `documentation`, `migration`
- 元 issue: なし（ローカル起票）

## 背景と課題

移行元サイトの検証スクリプトは Astro の出力構造を前提に、原稿の保存、URL、内部リンク、下書き、プレビュー用の noindex などを確認している。
vss に移行する場合、このスクリプトとビルド順序を見直す必要がある。
静的ホスティングの設定は利用できる可能性があるが、今回 vss の出力を使った検証は実施していない。

## 検討事項

- 移行前後の URL、公開ページ、内部リンク、フィード、Markdown 表示の比較。
- 下書きや非公開資料の混入、旧出力の残存、`robots.txt` と noindex の確認。
- JavaScript を使うページのブラウザー操作、アクセシビリティと配信アセットの確認。
- 出力ディレクトリを再生成する vss の動作と、ホスティング側の URL と 404 の設定。
