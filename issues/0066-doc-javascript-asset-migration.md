## 背景と課題

移行元サイトのトップページと About は Three.js を使い、Astro と Vite による依存関係の解決とバンドルに依存している。
vss は静的ファイルをコピーできるが、Astro コンポーネントと Vite のビルドをそのまま置き換えるものではない。
vss 自体にバンドラーの実装が必要と決まったわけではない。

## 検討事項

- 外部バンドラーで生成した JavaScript、CSS、3D モデルを静的ファイルとして取り込む手順。
- ページ固有の HTML とテンプレート、アセット参照、開発時と本番時の差異。
- 生成先の削除や入力と出力の衝突を避けるビルド順序。
- 操作、アクセシビリティ、JavaScript 無効時の代替表示の確認方法。
