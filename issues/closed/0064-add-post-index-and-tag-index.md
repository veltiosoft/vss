# 記事一覧とタグ一覧を生成する方法を検討する

- Created: 2026-10-28
- 状態: 解決済み
- 優先度: P2
- ラベル: `enhancement`, `migration`
- 元 issue: なし（ローカル起票）

## 背景と課題

移行元サイトには日付降順の記事一覧、タグ一覧、各タグの件数がある。
vss はタグごとのページを生成できるが、通常ページで投稿全体や全タグを一覧表示する方法は同梱スキルから確認できなかった。
実装前に現在のテンプレートコンテキストと生成機能を確認する。

タグページの並び順は既存の [タグページの投稿を pub_datetime でソートする](../tag-page-sort-by-pub-datetime.md) と関連する。

## 検討事項

- 対象を記事に限定する方法と、一覧用テンプレートに渡すメタデータ。
- 日付順、同日や日付欠落時の順序、タグの集計と URL エンコード。
- 下書きの除外（[0063](0063-add-draft-exclusion.md)）。
- 一覧ページと手書きページの出力衝突、変更時の再生成。

## 完了条件

- [x] 既存機能と必要な拡張を確認し、一覧生成の仕様を決定する。
- [x] 記事一覧とタグ一覧、並び順、空の一覧、非公開記事、増分ビルドを検証する。

## 解決方法

- 通常ページに `posts` と `all_tags` を提供し、通常の Markdown ページと対応するテンプレートで一覧を作成する方式にした。新しい一覧用出力先は自動生成しない。
- `is_post: true` の公開ページを記事一覧に含め、タグなし記事も対象とする。固定ページと一覧ページは既定で対象外になる。
- `all_tags` は対象記事のタグ名、URL、記事件数を提供し、タグ名昇順で並べる。同一記事の重複タグは 1 件として集計し、安全でないタグ名は除外する。
- 記事一覧と既存タグページを `pub_datetime` の降順で並べ、同日時は URL 昇順にする。RFC 3339 と `YYYY-MM-DD` を比較し、日付のみは UTC 午前 0 時、不正または未指定の日付は末尾とする。
- 既存タグページは互換性のため `is_post` に関係なく公開ページのタグを対象にする。通常ページの一覧対象とは異なることを文書化した。
- 記事リンクをパス要素ごとにエンコードし、一覧データが変わったときはすべての通常ページを再描画する。本文だけの変更時は変更ページの増分更新を維持する。
- 利用例は `site/docs/posts.md` と `skills/vss/SKILL.md` に記載し、`src/subcommand_build/tests/publication.rs` で空の一覧、日付順、タグ集計、下書き、変更、削除、リネーム、静的出力との重複を検証した。
- `cargo test --locked` と `cargo clippy --locked --all-targets -- -D warnings` を通過した。移行元の記事 39 件のコピーで `is_post` と日付フィールドを対応付け、公開 38 件の一覧生成と `serve` 中の更新も確認した。
