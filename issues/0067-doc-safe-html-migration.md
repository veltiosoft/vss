# 生 HTML を含む Markdown の安全な移行方法を整理する

- Created: 2026-10-28
- 状態: 未着手
- 優先度: P2
- ラベル: `documentation`, `migration`

## 背景と課題

移行元の Markdown には埋め込み投稿の `blockquote`、リンク、`script` などの生 HTML が含まれる。
Astro 側は HTML をサニタイズしており、vss の `allow_dangerous_html` は既定で無効である。
両者の出力が一致するとは限らないが、今回の調査では記事ごとの差分をビルドで確認していない。

## 検討事項

- 既定設定で生 HTML とその中のテキストがどのように扱われるかの実測。
- リンクや引用を Markdown に変換する手順と、表示差分を発見する方法。
- 許可リスト方式などを検討する場合の安全性と保守コスト。
- 危険な HTML の一括許可を移行の既定手順としないこと。
